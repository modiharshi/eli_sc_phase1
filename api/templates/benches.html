How bench size is worked out. The sources list only the judges named in their record: {{ '{:,}'.format(stats.one_judge) }} of {{ '{:,}'.format(stats.total) }} judgments ({{ (100 * stats.one_judge / stats.total)|round(0)|int }}%) list exactly one, and {{ stats.null_listed }} list none. So this page also reads the bench from the header of the English text, e.g. “(… AND Y. V. CHANDRACHUD, JJ.)”. Effective bench size is the larger of the two and is an estimate where it comes from the header (OCR errors can add or drop a name; the header text used is stored and shown on each judgment’s Judges tab, and agreement with the source list is measured in docs/BENCH_ESTIMATE.md). A header was found for {{ '{:,}'.format(stats.with_header) }} judgments; {{ '{:,}'.format(stats.not_derivable) }} judgments have no bench size from either route (no judges listed and no readable header).
