# ELI: Indian Supreme Court data platform

Beta platform that merges two open datasets of Indian Supreme Court judgments,
**Vanga** (Dattam Labs, AWS Open Data) and **Vaquill** (Open India Law, Hugging Face),
into one canonical PostgreSQL database with full provenance, and a web frontend
where every table and field is visible.

Runs on localhost (Docker Compose). See `docs/RUNBOOK.md` and `docs/DECISIONS.md`.
